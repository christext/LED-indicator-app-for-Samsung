This app simulates an LED status light using notifications. It's just a test app that's used on phones with a Samsung phone with a LED Light. It can only blink but you can change the color of them
This is my first app that I made with help of Android studio AI

Support androids from 8 and up
This is only used on Samsung devices with a status light LED in it. I tested on **Samsung Note9** with Android 10
